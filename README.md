# Placement Portal Application

This project is built using Flask, SQLAlchemy, HTML, CSS and Bootstrap.

There are three roles which interact with the placement system:

Admin 
- Approves companies
- Manages students and drives
- Monitors applications

Company
- Registers on the portal
- Creates placement drives
- Reviews student applications

Student
- Registers and logs in
- Views placement drives
- Applies for jobs
- Tracks application status
